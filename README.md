# RE9 Optimized Launcher
A simple batchfile tool that launches re9 (re9.exe) with additional command arguments that improves performance on SOME hardwares and also checks for REFramework.

**How to use?**:
- 1. Put the .bat file in you're game directory (usually at C:\Program Files (x86)\Steam\steamapps\common\RESIDENT EVIL requiem BIOHAZARD requiem).
- 2. Launch the .bat file, it will ask for admin rights, click yes, then enjoy.
 
__**WARNING**__ This doesn't mean it will improve performance on your hardware specifically, some users can have better and more smooth gameplay, some do not, for example for me, it improves my FPS a little bit but causes some spikes issues (limited at 120), so it depends, if it works better for you, i am happy, you're free to update and optimize this batchfile and made a better version for yourself.
